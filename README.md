# 🖱️ Virtual AI Mouse

A Python-based Virtual Mouse that uses **hand gestures via webcam** to control the computer cursor.  
Built using Computer Vision and AI techniques.

---

## 🚀 Features

- Move cursor using index finger ✋
- Left click gesture 👆
- Right click gesture ✌️
- Smooth real-time tracking using webcam
- No physical mouse required

---

## 🛠️ Tech Stack

- Python 🐍
- OpenCV 👁️
- MediaPipe ✋
- PyAutoGUI 🖱️
- NumPy
